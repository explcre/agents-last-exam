# Third-party attribution

## PrismarineJS

The environment is built entirely from the PrismarineJS project, all of it MIT and
all of it pure JavaScript.

| package | version | role |
|---|---|---|
| [`mineflayer`](https://github.com/PrismarineJS/mineflayer) | 4.25.0 | the bot client |
| [`flying-squid`](https://github.com/PrismarineJS/flying-squid) | 1.12.0 | the server |
| [`minecraft-data`](https://github.com/PrismarineJS/minecraft-data) | 3.113.1 | protocol and block tables |
| [`prismarine-registry`](https://github.com/PrismarineJS/prismarine-registry) | 1.12.0 | block id lookup |
| [`node-protodef`](https://github.com/ProtoDef-io/node-protodef) | 1.19.0 | packet serialisation |

Their MIT notices ship with the packages and are installed alongside them by
`env/packages-linux/mineflayer-runtime`.

## No Mojang material is used

This matters enough to state precisely, because the task looks like it should
involve Minecraft assets and it does not.

`flying-squid` is an independent reimplementation of the Minecraft server protocol
in JavaScript. **No Mojang jar is downloaded, no game client is installed, no
Minecraft asset, texture, sound, world file or save is redistributed**, and the task
does not require a Minecraft account or licence. The worlds are generated by
`flying-squid`'s own superflat generator and then overwritten by the task, and the
only "content" is block type names, which are protocol identifiers rather than
creative works.

`minecraft-data` contains protocol descriptions and block/item tables maintained by
the PrismarineJS community and distributed under MIT.

The practical consequence: everything this task ships can carry ALE's CC BY 4.0
dataset licence. A task built on recorded Minecraft gameplay video could not, since
Mojang permits publishing such video but grants no right to sublicense their assets.

## Corpus

The example and held-out worlds are produced by running the reference bot against
worlds this task builds, using the same runner the agent is given. They are recorded
output of an actual run, not authored by hand: a hand-written target could describe
a world no bot can physically produce, which would make the task unreachable rather
than hard.
